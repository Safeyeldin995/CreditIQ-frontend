# CreditIQ — منصة تحليل المخاطر الائتمانية

منصة ذكاء اصطناعي لتحليل مخاطر الائتمان لجمعية المبادرة المصرية.

## نشر المنصة على Vercel (مجاني)

### الخطوة 1 — رفع الملفات على GitHub

1. افتح **github.com** وسجل الدخول
2. اذهب إلى `github.com/Safeyeldin995/creditiqfront`
3. احذف الملفات القديمة
4. ارفع جميع ملفات هذا المجلد

### الخطوة 2 — النشر على Vercel

1. اذهب إلى **vercel.com** وسجل الدخول بحساب GitHub
2. اضغط **Add New Project**
3. اختر مستودع `creditiqfront`
4. اضغط **Deploy**

سيتم نشر الموقع تلقائياً في دقيقتين.

## تشغيل محلياً للتطوير

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:5173`

## أول دخول للنظام

1. اذهب إلى `/setup` في المتصفح
2. أنشئ حساب المدير الأول
3. سجل الدخول من `/login`
